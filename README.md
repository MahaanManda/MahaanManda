## What I'm building

- **[SecTriage](https://github.com/MahaanManda/sectriage)**: an LLM agent that triages security alerts using retrieval over MITRE ATT&CK technique notes, playbooks and organization policies. It includes an evaluation harness, a FastAPI service and tests. On 26 policy-dependent synthetic alerts, verdict accuracy rose from 81% (model alone) to 92% (agent). The data is synthetic and the samples are small, and the repo documents the results and limitations. Live demo: https://sectriage.onrender.com
